Task 03 — Create and Run Your First Docker Container

Dockerfile
----------
FROM node:24-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install

COPY app.js ./

EXPOSE 3000

CMD ["npm", "start"]

Docker commands used
--------------------
docker --version — Docker CLI version: 29.9.3.
docker info --format '{{.ServerVersion}}' — confirmed Docker Engine version 29.9.3.
docker build -t my-node-app:v1 . — built the image; image ID: 1ec40219352a.
docker run -d --name my-node-container -p 3000:3000 my-node-app:v1 — started the container in the background; container ID: d0a720f44ffa.
docker ps — listed running containers.
docker inspect my-node-container — inspected container configuration and runtime state.
docker logs my-node-container — displayed the application logs.
docker images — listed local images.
docker stop my-node-container — stopped the container.
docker rm my-node-container — removed the stopped container.
docker ps -a --filter name=my-node-container — confirmed that the container was removed.
