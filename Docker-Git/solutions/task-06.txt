Rebase and merge
----------------
Rebase replays commits onto a new base, creating a linear history and new commit hashes. Use it to clean up a private branch; don't rebase commits already shared with others.

Merge preserves both histories and adds a merge commit. Use it when the branch structure should remain visible.
